📊 Project Title: Pizza Sales Analysis Dashboard (SQL + Power BI)
🔎 Description

This project focuses on analyzing pizza sales data to extract meaningful business insights and support data-driven decision-making. The dashboard provides a comprehensive overview of key performance metrics including total revenue, total orders, average order value, and quantity sold.

Using SQL and Power BI, the dataset was cleaned, transformed, and modeled to evaluate sales performance across:

Pizza categories (Classic, Supreme, Chicken, Veggie)

Pizza sizes (Small, Medium, Large, XL)

Top 5 best-selling pizzas

Sales trends by hour, weekday, and month

Ingredient usage frequency

The dashboard helps identify peak sales hours, top-performing products, customer ordering patterns, and overall business performance trends.
